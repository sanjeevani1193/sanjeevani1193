### 🚀 Selected Projects

#### 🔐 Master's Thesis — Secure Multilingual LLM Systems
*Multilingual NLP · LLM Inference · Retrieval-Augmented Generation · Backend Engineering*

Developing a self-hosted multilingual LLM system for privacy-sensitive document processing, supporting **summarization, translation, and question answering in English, Hindi, and Odia**.

- Serving a 4-bit quantized Gemma 3 4B model using vLLM.
- Implemented document retrieval using SentenceTransformers and session-isolated ChromaDB.
- Built a FastAPI backend and Streamlit frontend with session management and automatic expiry.
- Investigating multilingual adaptation strategies and systematic model evaluation.

**Stack:** Python, Gemma 3, vLLM, FastAPI, Streamlit, ChromaDB, SentenceTransformers.

#### 🚲 [CityPulse AI — Time-Series Forecasting & ML Engineering](https://github.com/sanjeevani1193/CityPulse-AI)
*Data Engineering · Deep Learning · Forecasting · Cloud · MLOps*

An end-to-end urban mobility analytics and ML engineering project using NYC Citi Bike data.

- Processed **33.3M+ ride records** with validation, integrity checks, and recoverable checkpoints.
- Evaluated **5 forecasting approaches**, achieving a preliminary **18.1% reduction in test MAE** against a daily seasonal baseline.
- Developed FastAPI inference services for XGBoost, PyTorch, and TensorFlow models.
- Integrated Docker, MLflow experiment tracking, GitHub Actions CI, and GCP Cloud Storage.

**Stack:** Python, SQL, DuckDB, PyTorch, TensorFlow, XGBoost, FastAPI, Docker, MLflow, GCP.

#### 📚 [Book Recommendation System — Bachelor's Thesis](https://github.com/sanjeevani1193/Book-Recommendation-System-Using-Machine-Learning-Techniques)
*Machine Learning · Recommendation Systems · Model Evaluation*

Designed and benchmarked **4 recommendation approaches** across 2 datasets containing approximately **7.1 million user ratings**.

Compared content-based filtering, collaborative filtering, cascade hybrid, and weighted hybrid approaches using quantitative evaluation and user-focused testing.

**Stack:** Python, pandas, NumPy, scikit-learn.
